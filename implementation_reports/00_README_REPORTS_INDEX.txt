QUALITY BOBA (SQUAD 60) - IMPLEMENTATION SPECIFICATION REPORTS INDEX
================================================================================

This archive contains 11 dedicated, comprehensive engineering implementation
reports covering all critical unimplemented features for CSCE 331 Project 3.

INDEX OF REPORTS:
--------------------------------------------------------------------------------
1.  01_auth_api_implementation_report.txt
    - Google OAuth 2.0 architecture, role-based access control, session security,
      and dedicated manager access for 'reveille.bubbletea@gmail.com'.

2.  02_translation_api_implementation_report.txt
    - Machine Translation API (Google Translate / LibreTranslate) with caching,
      bilingual kiosk dropdown (EN/ES/HI), and culinary terminology mapping.

3.  03_weather_api_implementation_report.txt
    - Weather Forecast API (Open-Meteo) for College Station, TX, with 15-minute
      caching and dynamic hot/chilly/rainy drink recommendations.

4.  04_personal_assistant_api_implementation_report.txt
    - Personal Assistant (GenAI BobaBot) via Google Gemini 1.5 Flash, providing
      dietary inquiry assistance and one-click "Add to Cart" recommendations.

5.  05_beyond_feature_points_loyalty_system.txt
    - Above-and-Beyond Customer Feature 1: Phone-number loyalty rewards system,
      points accrual (10 pts/$1), tiered voucher redemption, and database schema.

6.  06_beyond_feature_seasonal_and_daily_deals.txt
    - Above-and-Beyond Customer Feature 2: Manager-controlled Taco Tuesday and
      Happy Hour daily deals engine with dynamic kiosk badge and cart discounts.

7.  07_persona_maria_accessibility_report.txt
    - Accessibility Persona 1 (Maria): Bilingual Spanish localization, boba
      culinary terminology mapping, visual ingredient icons, persistent state.

8.  08_persona_vishnu_accessibility_report.txt
    - Accessibility Persona 2 (Vishnu): Glaucoma WCAG 2.1 AAA high-contrast mode,
      3px solid focus rings (':focus-visible'), non-color reliant state badges.

9.  09_persona_carol_accessibility_report.txt
    - Accessibility Persona 3 (Carol): Macular degeneration large text mode,
      oversized 56x56px touch targets, explicit "Clear Cart" confirmation modal.

10. 10_manager_reports_expansion_report.txt
    - Manager Dashboard expansion: Multiple day-to-day reports (Hourly Sales Chart,
      Best Sellers ranking, Inventory Depletion Reorder, End-of-Day Z-Report).

11. 11_automated_testing_methodology_report.txt
    - Test-Driven verification using Jest and Supertest to automate integration
      testing across all API endpoints, database queries, and transactions.
